# Sistema de Gerenciamento de Transporte Escolar

Este projeto consiste no desenvolvimento de um sistema para gerenciamento do transporte escolar no município de Caxias - MA.

## 📌 Descrição
O sistema tem como objetivo otimizar a gestão do transporte de estudantes, permitindo o acompanhamento de rotas, organização de usuários e melhoria na comunicação entre motoristas, alunos e a administração pública.

## 🧩 Arquitetura
O sistema é composto por:
- Aplicativo mobile para motoristas (Flutter)
- Aplicativo mobile para alunos (Flutter)
- Sistema web administrativo (responsável por esta implementação)

## 🛠️ Tecnologias utilizadas
- HTML, CSS, JavaScript
- Integração com APIs REST

## 👨‍💻 Minha contribuição
Atuei no desenvolvimento da plataforma web administrativa, sendo responsável pela implementação das interfaces e funcionalidades de gestão utilizadas pela prefeitura.

## 🌍 Contexto
Projeto desenvolvido no contexto de atividades vinculadas à Prefeitura de Caxias - MA, com foco em impacto social e melhoria da gestão pública.
